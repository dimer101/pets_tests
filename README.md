# Petstore API tests (Python + pytest)

Тестовое задание: пример проекта автотестов для сервиса Swagger Petstore.

## Стек

Python 3
requests
pytest

## Запуск

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
pytest -v

```

## Тесты:

Создание и получение питомца

Обновление данных питомца

Повторное создание питомца с тем же ID

Удаление питомца

Получение несуществующего питомца
